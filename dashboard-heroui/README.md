# مشروع هلا كوميرس — React

المشروع الأساسي للتطوير هو هذا المجلد. React + Vite + HeroUI، مع نفس التصميم المضغوط المعتمد وخط IBM Plex Sans Arabic واتجاه RTL. جميع الخطوط والشعار والأيقونات داخل المشروع، ولا يحتاج المصدر إلى ملفات من مجلدات النسخ السابقة.

## التصميم المعتمد

التصميم الحالي هو الأساس الدائم لباقي الموقع. راجع [DESIGN.md](DESIGN.md) قبل بناء أي صفحة جديدة، وأعد استخدام الغلاف والمكونات والأنماط المشتركة. يشمل الاعتماد عدًّا بسيطًا للأرقام لمدة 400ms عند ظهورها، مع احترام تقليل الحركة.

## التشغيل

يتطلب Node.js 20.19+ أو 22.12+ ومدير حزم npm أو pnpm.

```sh
cd "/Volumes/Work/تصميم هلا /dashboard-heroui"
npm install
npm run dev
```

المعاينة: http://127.0.0.1:4181/

يمكن استخدام `pnpm install` و`pnpm dev` بدلًا من npm. يوجد `pnpm-lock.yaml` بإصدارات مقفولة. إذا طلب pnpm السماح ببناء esbuild أثناء التثبيت، اسمح لهذه الحزمة الرسمية.

```sh
npm run build
npm run preview
```

`dist/` هو ناتج React المعتاد بملفات JavaScript وCSS وأصول منفصلة. يُرفع محتواه كاملًا إلى الاستضافة. المشروع يستخدم HashRouter لكي تعمل الروابط المباشرة على الاستضافة الثابتة دون إعداد إعادة كتابة المسارات.

لتصدير نسخة HTML مستقلة اختيارية:

```sh
npm run export:html
```

ينتج `dist-standalone/index.html` ويُحدّث `../hala-dashboard.html` و`../hala-dashboard-heroui.html`. لا يُعدّل النسخ المعتمدة المؤرشفة.

## الصفحات

| الرابط | الحالة |
|---|---|
| `/#/` | لوحة التحكم: الطلبات والشحنات والمالية في صفحة واحدة كما في التصميم المعتمد |
| `/#/affiliate` | الأفلييت: رابط الإحالة والأرباح والعمولات والسحب والحسابات، ببيانات الصورة الأصلية |
| `/#/orders` | صفحة مستقلة للطلبات بإحصائياتها الأصلية؛ تفاصيل السجلات غير متاحة بعد |
| `/#/shipments` | صفحة مستقلة لإحصائيات الشحنات المتاحة |
| `/#/wallet` | صفحة مستقلة للملخص المالي المتاح |

المنتجات والتكاملات وطلبات الاستيراد والحاسبة والإعدادات تظل عناصر مرئية حتى تتوفر مراجعها. لم تُضف لها صفحات أو بيانات وهمية.

## تنظيم المصدر

```text
src/
  App.jsx                      تعريف المسارات والمزوّدات
  main.jsx                     نقطة تشغيل React
  config/navigation.js         القائمة وعناوين الصفحات
  config/account.js            اسم الحساب ومعرّف البائع الظاهر
  context/DashboardContext.jsx الفترة المشتركة بين الصفحات
  pages/                       صفحة مستقلة لكل مسار
  components/layout/           القائمة والهيدر والغلاف المشترك
  components/dashboard/        الفلاتر والمؤشرات والرسوم والأقسام
  components/ui/               الأيقونات والنافذة المشتركة
  data/dashboard.json          نفس الداتا الأصلية
  assets/                      الشعار والأصول المحلية
  fonts/                       خط IBM Plex Sans Arabic محليًا
  styles.css                   ثوابت الهوية والتصميم المعتمد
```

الأيقونات الحالية مكوّنات React من `@gravity-ui/icons`، وهي مجموعة Gravity المتوافقة مع الأسلوب الافتراضي لـ HeroUI. الأيقونات مضمّنة محليًا في البناء ولا تتطلب طلبات شبكة. معرّف البائع `86jdk5` موجود في `src/config/account.js` ويظهر بجانب زر ينسخ المعرّف نفسه؛ عند ربط الحساب لاحقًا يُستبدل بقيمة المستخدم من الخدمة.

لإضافة صفحة: أنشئ ملفًا في `pages/`، أضف Route في `App.jsx`، ثم أضف المسار وعنوانه في `config/navigation.js`. استخدم المكوّنات وثوابت التصميم المشتركة.

## البيانات والحدود

الإحصائيات والسجلات المرجعية من الصور الأصلية، مع توضيح البيانات التجريبية أو غير المتاحة. لا يوجد API؛ البحث والتصفية والنماذج والإضافات المحلية لمعاينة التصميم، ولا تعدّل حسابات أو طلبات حقيقية. منحنى الإيرادات توضيحي فقط. الدول والمنتجات والمتاجر متاحة كإجماليات فقط. الفترة المشتركة تحتفظ بقيمتها أثناء التنقل، وأي فترة أخرى تعرض حالة عدم توافر البيانات.

الصفحات الحالية وتفاصيل وظائفها وحدود بياناتها موثقة في `DESIGN.md`. تشمل الطلبات والدرافت وإضافة طلب والمنتجات والشحنات وربط المتاجر وطلبات الاستيراد والمحفظة والعروض والحاسبة والإعدادات وصفحة هلا التعريفية في `/home`.


مصدر الأفلييت `src/data/affiliate.json`: رابط الإحالة مطابق للصورة، عمولة الطلب المسلّم $0.25، الأرصدة والحسابات والطلبات المسلّمة صفر. زر السحب معطّل لعدم وجود رصيد، ولا يوجد ربط سحب أو تسجيل حسابات فعلي. خيار المشاركة يعرض الرابط ونسخه؛ يمكن للمستخدم فتح مشاركة الجهاز من النافذة إن دعمها المتصفح.

صور الصفحات القادمة تُستخدم لاستخراج الداتا والمحتوى والوظائف فقط، ثم يعاد تصميم الصفحة بستايل هلا الحالي. لا تُنسخ الواجهة القديمة.

نسبة الشحن الدائرية 50% اختارها المستخدم للعرض، في `src/config/chartPresentation.js`؛ أعداد الشحنات الأصلية لم تتغير. المؤشرات وأسباب فشل الشحنات والنسب داخل كارت واحد بخلفية بيضاء موحّدة وفواصل رفيعة. دائرة نسبة الشحن أولًا على اليمين، ثم أسباب الفشل في المساحة المتبقية من لقطة مستقلة في `src/data/shipping-failures.json`. الإجمالي صغير فوق دائرة الشحن، وأزيلت دائرة التسليم فقط دون تغيير مؤشرها الأصلي. منطقة الرسوم عمود لنسبة الشحن وثلاثة أعمدة للأسباب على الكمبيوتر، ومتراصة على الموبايل.

نسب الطلبات تعرض التأكيد والإلغاء، ثم أسباب إلغاء الطلبات بعرض العمودين الآخرين، دون دائرتي التأجيل والوهمي. أسباب الإلغاء من `src/data/order-cancellations.json`؛ القيم مستقلة عن مؤشرات الصفحة الأصلية.

كارت «أفضل ٥ منتجات» في الرئيسية بعد الشحنات، ببيانات وصور توضيحية سمح بها المستخدم للمعاينة. مصدره `src/data/top-products.json`، والنسب بجوار المؤكد والمشحون فقط من إجمالي عمود كل منهما للمنتجات الخمسة. الجدول المضغوط يتضمن NDR وAOV، ومتوسط قيمة الطلب يحسب من الإيراد مقسومًا على كل الطلبات. الصور دون شارة دولة. إجمالياته منفصلة عن بيانات الأقسام الأخرى.
