# Hala dashboard

التصميم معتمد وثابت. راجع `../DESIGN_LOCK.md` قبل أي تطوير لاحق.

افتح `../hala-dashboard.html` مباشرة في المتصفح؛ الملف يتضمن الخطوط والشعار والأيقونات ومكتبة الرسوم ولا يحتاج إنترنت لعرض اللوحة.

المصادر القابلة للتعديل:

- `styles.css`: النظام البصري والاستجابة للشاشات.
- `data.json`: بيانات الصور الأصلية، مع توضيح أن منحنى الإيرادات تقريبي.
- `app.js`: التنقّل والبحث والفترة والرسوم.
- `build.py`: تجميع ملف HTML المستقل. يشغّل باستخدام `python3 dashboard/build.py` من المجلد الرئيسي.

لا يوجد اتصال API في هذه النسخة. ملفات التراخيص محفوظة ضمن `vendor`.

النسخة المعتمدة محفوظة في `releases/2026-10-23/`، والصورة الكاملة بصيغة JPG في `../hala-dashboard-approved.jpg`.
